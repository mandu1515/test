# Boram 근무 관리

관리자·직원용 PC/모바일 근무 관리 체험 프로젝트입니다. 현장 출퇴근 인증 코드는 Flask 서버가 SQLite에 저장하고 검증합니다.

## 실행

Windows 탐색기에서 `start-boram.cmd`를 더블클릭합니다. 실행에 실패하면 창에 오류가 표시되며, 키를 누를 때까지 창이 열려 있습니다.

PowerShell에서 실행하려면 Boram 폴더로 이동한 뒤 아래 명령을 사용합니다.

```powershell
.\start-boram.ps1
```

실행기는 Flask가 없으면 설치하고, 관리자 발급 키를 화면에 표시한 뒤 서버를 시작합니다. 현재 PowerShell 창에 `BORAM_ATTENDANCE_ADMIN_KEY`가 설정되어 있으면 그 값을 사용합니다. 서버를 종료하려면 `Ctrl+C`를 누르세요.

1. 같은 네트워크의 관리자와 직원이 모두 `http://<서버-PC의-LAN-IP>:5000`에 접속합니다. QR에는 관리자가 접속한 주소가 포함됩니다.
2. 관리자는 **출퇴근 인증** 화면에 발급 키를 입력하고 OTP 갱신 또는 QR 재발급을 누릅니다.
3. 직원은 **출퇴근 인증** 화면에서 6자리 OTP를 입력합니다. QR은 휴대전화 기본 카메라로 열거나 인증 화면에 링크를 붙여 넣고 확인합니다. 앱 내부 카메라는 HTTPS 또는 localhost에서 지원 브라우저로 사용할 수 있습니다.

기본 설정에서 OTP와 QR은 각각 5분 동안 유효합니다. 같은 방식의 코드를 재발급하면 이전 코드는 만료됩니다. 유효한 코드는 여러 직원이 사용할 수 있습니다. 인증 DB는 기본적으로 `dist/users.db`이며 `BORAM_DB_PATH`로 경로를 지정할 수 있습니다.

위 명령은 신뢰할 수 있는 네트워크에서 개발용으로 실행하는 방법입니다. 외부 접속 환경에서는 HTTPS와 운영용 WSGI 서버를 사용하세요.

## 체험 계정

| 항목 | 값 |
| --- | --- |
| 관리자 아이디 | admin |
| 직원 아이디 | staff1 ~ staff6 |
| 비밀번호 | 임의의 4자 이상, 실제 비밀번호 입력 금지 |
| 로그인 추가 인증 | 130958 (체험 유효시간 3분) |
| 직원 가입 사업장 코드 | BRM2026 |

왼쪽 메뉴의 역할 전환 또는 모바일 더보기에서 관리자·직원을 전환할 수 있습니다. 같은 브라우저의 데이터를 공유하므로 직원 신청을 관리자 화면에서 처리할 수 있습니다.

## 구현 범위

- 로그인·회원가입·사업장 연결·추가 인증 UI
- 관리자 대시보드, 결원 알림, 직원 검색·등록·수정
- 월/주/목록 일정, 날짜별 필요 인원과 직원 배정, 결원 표시
- 개인 일정 및 정상·지각·결근·예정 색상 캘린더
- 서버 기반 출퇴근 OTP·QR 검증, 근무기록 검색·수정·결근 처리·삭제
- 직원 근무시간 수정 요청 및 관리자 승인·반려
- 실제 기록 기반 분 단위 근무시간, 수당 입력, 급여 확정·해제
- UTF-8 CSV 내보내기, 브라우저 인쇄를 통한 PDF 저장
- 근로조건 6개 탭: 조건, 고정 스케줄, 4대보험, 휴가, 계약서, 계정
- 요일별 고정 스케줄의 선택 월 적용 및 중복 배정 방지
- 휴가 부여·신청·승인·반려, 잔여 일수 표시
- 1MB 이하 PDF/PNG/JPG 계약서 등록·다운로드·삭제
- 사업장 운영기간, 연락처, 인증 정책 설정 UI
- 알림 분류·검색·읽음 처리
- 데스크톱 사이드바, 모바일 하단 탐색 및 반응형 표/카드

## 소스 구조

```text
dist/
  index.html       진입 HTML
  styles.css       디자인 토큰과 반응형 스타일
  model.js         시간, 급여, 결원 계산 및 샘플 데이터
  app.js           화면 렌더링, 이벤트, 저장, 다운로드
tests/
  model.test.cjs    시간·급여·결원·CSV 테스트
  screens.test.cjs  화면 생성 및 데이터 변경 흐름 테스트
package.json       npm test 명령
README.md          실행·구현 범위 안내
```

`app.js` 상단의 공통 컴포넌트와 `shell()`이 화면 골격을 만듭니다. `render()`가 해시 주소를 화면에 연결하고, `data-action` 클릭과 `data-form` 제출 이벤트가 데이터를 변경합니다. `model.js`는 DOM 없이 검증할 수 있는 계산 로직입니다. 실제 API 연결 시 이 이벤트 처리부의 브라우저 데이터 변경을 API 호출로 교체하세요.

주요 주소: `#/home`, `#/employees`, `#/employee/e1`, `#/schedule`, `#/attendance`, `#/records`, `#/payroll`, `#/conditions`, `#/leave`, `#/store`, `#/notifications`.

## 저장 및 계산 규칙

- 데이터: 현재 브라우저의 localStorage `boram-work-v1`. 로그인 체험 상태: sessionStorage `boram-session`.
- 첫 실행 시 현재 월의 샘플 직원 6명과 일정·과거 출퇴근기록을 생성합니다.
- 종료시각이 시작시각보다 이르면 다음 날 퇴근으로 계산합니다. 24시간 이상 연속 근무는 지원하지 않습니다.
- 기록에 출근·퇴근이 모두 있고 결근이 아닌 경우에만 근무시간에 포함합니다.
- 월 기본급은 월 전체 분 합계 ÷ 60 × 현재 직원 시급으로 계산 후 반올림합니다. 일별 표시의 반올림 합계와 차이가 있을 수 있습니다.
- 기록 또는 시급·수당 변경 시 관련 급여 확정을 해제합니다. 현재 시급 변경은 과거 월에도 반영되므로 실제 급여 운영에는 기간별 시급 이력 모델이 필요합니다.
- 주휴·야간·기타 수당은 관리자 직접 입력입니다. 공제·세금·법적 지급요건을 자동 계산하지 않습니다.
- 승인한 휴가의 입력 일수를 부여 일수에서 차감합니다. 휴가 종류별 법적 산정 규칙은 포함하지 않습니다.
- 사업장 설정의 체험 데이터 초기화는 이 앱의 샘플 데이터를 새로 만듭니다.

## 실제 운영과 구분되는 부분

현장 인증 코드는 서버에서 공유하지만 로그인, 직원 정보, 근무 배정, 출퇴근 기록, 급여는 브라우저별 체험 데이터입니다. 직원이 인증하면 해당 브라우저의 배정과 출퇴근 기록에 반영됩니다. 관리자 발급 키는 현장 코드 발급 API에 적용됩니다.

실제 서비스에는 서버 인증·권한, 사용자별 데이터 접근 제어, DB·파일 저장소, 인증 제공업체, 감사 이력과 백업을 별도로 구현해야 합니다. 현재 저장소는 민감한 개인정보나 실제 계약서의 운영 저장소로 사용하지 마세요.

## 검증

Node.js 18 이상에서 `npm test`를 실행합니다. 외부 패키지 설치는 필요 없습니다.

JavaScript 문법 검사와 7개 테스트가 통과했습니다. 테스트는 익일 퇴근, 휴게 공제, 급여 필터·재계산, 확정 해제, 결원 계산, CSV 처리, 화면 HTML 생성, 고정 스케줄 중복 방지를 확인합니다. 화면 생성 테스트는 Node VM 기반으로 실제 브라우저의 레이아웃·카메라·다운로드·인쇄 검증을 대신하지 않습니다. 이 제작 환경에서는 실제 브라우저 시각 검증을 수행하지 못했습니다.

폰트는 Google Fonts의 Noto Sans KR을 선택적으로 불러오며 연결이 없으면 시스템 글꼴을 사용합니다.
